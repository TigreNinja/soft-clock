SoftClock

Reloj analógico encapsulado en un único archivo de JavaScript. Geometría suave, cuatro temas incluidos y un punto orbital que dibuja el minuto en curso. Sin dependencias.

randomize() genera una paleta HSL coherente cada vez.

Temas incluidos

porcelana
grafito
salvia
niebla
<!-- Declarativo: cero JavaScript -->
<div data-soft-clock data-theme="grafito" data-size="200"></div>
<script src="softclock.js"></script>

// Programático: control total
const clock = SoftClock.mount('#miDiv', { theme: 'salvia', size: 220 });
clock.randomize();   // paleta suave aleatoria
clock.setTheme('niebla');
clock.destroy();
